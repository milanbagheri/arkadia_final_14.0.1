# ARCADIA V — بسته یکپارچه نهایی مرحله ۱۴

این بسته، پروژه یکپارچه مرحله ۱۴ و آخرین مرحله توسعه فعلی ARCADIA است.

## اجرا در ویندوز / لینوکس
نیازمند Node.js نسخه ۲۰ یا جدیدتر:

```bash
npm install
npm test
npm start
```

مرورگر: `http://localhost:3000`

## بازی آنلاین چهار نفره
1. یک بازیکن اتاق می‌سازد و کشورش را انتخاب می‌کند.
2. سه بازیکن دیگر با کد اتاق وارد می‌شوند و هرکدام کشور متفاوتی انتخاب می‌کنند.
3. هر چهار بازیکن «آماده‌ام» را می‌زنند.
4. میزبان مسابقه را شروع می‌کند.
5. هر بازیکن در هر نوبت یک اقدام اقتصادی، سیاسی، دیپلماتیک یا نظامی انتخاب می‌کند. سرور پس از دریافت هر چهار اقدام، نوبت را حل و نتیجه را برای همه منتشر می‌کند.

## Render
`render.yaml` برای سرویس Node و Persistent Disk تنظیم شده است. دیسک پایدار در پلن‌های رایگان Render ارائه نمی‌شود؛ پلن سازگار لازم است.

## مسیرهای سرویس
- صفحه بازی: `/`
- WebSocket: `/ws`
- سلامت: `/healthz`
